## 🚀 Công nghệ sử dụng
### Frontend
- **Framework:** React  + Vite
- **Styling:** Tailwind CSS  (Modern UI/UX)
- **State Management:** Zustand
- **Routing:** React Router Dom 
- **UI Components & Icons:** Lucide React, React Icons, SweetAlert2
- **Notifications:** React Hot Toast
- **Charts:** Recharts (Dành cho Dashboard quản trị)
- **Drag & Drop:** @dnd-kit (Sắp xếp hình ảnh/danh mục)
### Backend
- **Core:** Java + Spring Boot 
- **Security:** Spring Security & JWT (JSON Web Token)
- **Database:** PostgreSQL
- **ORM:** Spring Data JPA
- **Storage:** Cloudinary (Quản lý hình ảnh sản phẩm)
- **Validation:** Spring Boot Starter Validation

## ✨ Tính năng chính
### 🛒 Dành cho Khách hàng (Client)
- **Trang chủ & Tìm kiếm:** Giao diện hiện đại, bộ lọc sản phẩm thông minh (theo hãng, giá, cấu hình).
- **Chi tiết sản phẩm:** Xem thông tin, cấu hình chi tiết và đánh giá từ người dùng khác.
- **Giỏ hàng & Thanh toán:** Quy trình thanh toán tối ưu (Mobile responsive), tích hợp nhiều phương thức vận chuyển.
- **Tài khoản cá nhân:** Quản lý lịch sử đơn hàng, thông tin cá nhân và trạng thái vận chuyển.
- **Đánh giá (Review):** Người dùng có thể gửi đánh giá và nhận xét về sản phẩm đã mua.
### 🔐 Dành cho Quản trị viên (Admin Dashboard)
- **Quản lý sản phẩm:** Thêm/sửa/xóa sản phẩm, quản lý kho hàng và thuộc tính biến thể.
- **Quản lý hình ảnh:** Upload và sắp xếp ảnh sản phẩm linh hoạt qua Cloudinary.
- **Quản lý đơn hàng:** Theo dõi trạng thái đơn hàng, xác nhận và cập nhật tiến độ giao hàng.
- **Quản lý đánh giá:** Kiểm duyệt và phản hồi các đánh giá từ khách hàng.
- **Thống kê:** Biểu đồ doanh thu và báo cáo tăng trưởng trực quan với Recharts.
- **Phân quyền:** Hệ thống Role-based Access Control (RBAC) bảo mật tuyệt đối.
